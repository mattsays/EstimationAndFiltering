UKF vs. CKF Weight Relationship
Equivalence of Cubature Kalman Filter to Unscented Kalman Filter with \(\lambda = 0\)
Unscented Kalman Filter (UKF)
Uses \(2n_x+1\) sigma points with scaling parameter \(\lambda\):
\(\displaystyle W_0 = \frac{\lambda}{n_x + \lambda}\)
\(\displaystyle W_i = \frac{1}{2(n_x + \lambda)}, \quad i = 1, \dots, 2n_x\)
→
Setting Parameter \(\lambda = 0\)
Setting the scaling parameter to zero eliminates the central point weight:
\(\displaystyle W_0 = \frac{0}{n_x + 0} = 0\)
\(\displaystyle W_i = \frac{1}{2(n_x + 0)} = \frac{1}{2n_x}\)
→
Cubature Kalman Filter (CKF)
Employs spherical rule with \(2n_x\) cubature points:
\(\displaystyle \text{No Central Point } (\mathcal{X}_0 \text{ vanishes})\)
\(\displaystyle \omega_i = \frac{1}{2n_x}, \quad i = 1, \dots, 2n_x\)
From now on: \(\displaystyle 2n_x = m\)
