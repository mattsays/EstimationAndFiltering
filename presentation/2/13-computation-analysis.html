Computational Cost: CKF vs SCKF
Flops per recursion cycle, with \(n_x\), \(n_z\) and \(m\) the state, measurement and cubature-point counts
CKF
\(\displaystyle C = 4mn_x^2 + \tfrac{2}{3}n_x^3 + mn_x(2n_z+3) + 6n_x^2\)
\(\displaystyle {}+ mn_z(2n_z+1) + n_xn_z(6n_z+1) + \tfrac{14}{3}n_x\)
\(\displaystyle {}+ n_z^3 + 5n_z^2 + \tfrac{1}{2}n_z - 3\ \ \text{flops}\)
SCKF
\(\displaystyle C = 6mn_x^2 + 2n_x^3 + mn_x(4n_z+9) + 2n_x^2n_z\)
\(\displaystyle {}+ \tfrac{1}{2}mn_z(5n_z+11) + n_xn_z(4n_z+1) + n_x\)
\(\displaystyle {}+ \tfrac{7}{3}n_z^3 + \tfrac{1}{2}n_z^2 + \tfrac{19}{6}n_z\ \ \text{flops}\)
↓ \(n_x \gg n_z\) and \(m = 2n_x\) ↓
CKF
\(\displaystyle C_{\mathrm{CKF}} \approx \tfrac{26}{3}\,n_x^{3}\)
SCKF
\(\displaystyle C_{\mathrm{SCKF}} \approx 14\,n_x^{3}\)
SCKF / CKF
\(\displaystyle C_{\mathrm{SCKF}}\,/\,C_{\mathrm{CKF}} \approx 1.6\)
