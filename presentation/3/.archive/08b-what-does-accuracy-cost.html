What does accuracy cost?

Cost is one number per update. Accuracy is not: it changes with the scenario.

Cost tracks the number of evaluations of the radar model: EKF 1, CKF 8, UKF 9. The CKF skips the UKF central point, so it is the cheaper of the two.

Cost is a property of the rule; accuracy is a property of the regime. At 100 m the three nonlinear filters tie, at 1,200 m the EKF error is twice the CKF. Rank filters per regime, never on one pooled number.
